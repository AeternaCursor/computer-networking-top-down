- 教材：Kurose & Ross《计算机网络：自顶向下方法》第 8 版

- 语言：Python 3.11+（涉及底层细节处用 C 说明）

## 一、方法论：每个项目走一遍实践论循环

```
实践一：抓包 / 用现成工具观察现象          （感性认识）
   ↓
认识一：读对应章节，提炼该层的核心矛盾      （理性认识）
   ↓
实践二：亲手实现项目                        （能动地改造世界）
   ↓
认识二：写博客复盘，用原理解释实验数据      （再认识）
   ↓
下一个项目调用并深化旧知识                  （螺旋上升）
```

## 二、全书本质：五对主要矛盾

| 层 | 主要矛盾 | 解决方案 |
|---|---|---|
| 应用层 | 千变万化的应用需求 vs 统一的进程通信抽象 | HTTP / DNS / SMTP / socket |
| 传输层 | 不可靠的 IP 之上提供可靠；时效 vs 完整 | TCP / UDP / 拥塞控制 |
| 网络层 | 全局寻址路由 vs 有限的带宽与路由器资源 | IP 尽力而为 / 路由算法 / NAT |
| 链路层 | 多主机共享同一介质 vs 信道冲突 | CSMA / 以太网 / 交换机 |
| 安全 | 网络的开放性 vs 机密性/完整性/认证 | 密码学 / TLS / 防火墙 |

## 四、每个项目的博客骨架（projects/pXX-xxx/blog.md）

1. **现象**：抓包 / 实验看到了什么
2. **矛盾**：这个协议解决什么问题
3. **设计**：为什么这样设计，权衡了什么
4. **实现**：关键代码走读
5. **验证**：实验数据（RTT 表、吞吐曲线、状态转换图）
6. **升华**：书中原理与我的实现对照；还有什么没做

## 五、目录结构

```

```

## 六、环境

- Python 3.11+（pip、venv）
- Wireshark（安装时勾选 Npcap）
- git + GitHub

## 七、规约

- 一次只做一个项目：做完写博客 → commit/push → 检验题通过 → 开下一个
- 每个项目结束做 3-5 道费曼式检验题，讲得清楚才算内化
- 博客中文，只写干货
